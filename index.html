HX Effects · HX Stomp · HX Stomp XL · Model Renamer

Rename the models on your HX

Drop in your firmware and give every model a name that says what it is: Boss SD-1 instead of Stupor OD. Then download a new .hxf with every checksum fixed, plus your presets with their footswitch labels updated. It all runs in this browser. Nothing is uploaded anywhere.

Unofficial and experimental. This isn't made or supported by Line 6, and installing modified firmware is at your own risk. Only the model names change: no sound, preset or NAM code is touched. If anything goes wrong, the Recovery steps put the stock firmware back.

2

Load your firmware

A 3.80.0 file for the HX Effects, HX Stomp or HX Stomp XL: stock, the NAM A2 Lite build, or one you renamed here before.

3

Name the models

Up to 16 characters each. Suggested names come from the HX Effects manual's "Based On" list and, for amps, preamps and cabs, from helixhelp.com's model list. Line 6 Originals keep their names.

Load a firmware file in step 1 first.

4

Add your setlist

Optional, but recommended if you have presets. The setlist you exported from HX Edit in step 1 holds every preset in its slot, so one file fixes them all and nothing has to be put back by hand. Single .hlx presets work too.

5

Build

Your renamed firmware, plus your fixed presets if you added any. The page checks the new firmware from scratch before it gives it to you.

6

Install the firmware

The same way as any Line 6 update.

  1. In HX Edit, back up your presets and IRs, then close HX Edit.
  2. If you got a .zip, open it to get the .hxf inside. Open Line 6 Updater, choose Choose File, and pick the renamed .hxf.
  3. Let it finish, and let the unit restart on its own.
  4. Open the model list: Distortion should now show Boss SD-1 where Stupor OD was.

Footswitch labels in your existing presets keep Line 6's names. A preset saves each footswitch's label when its block is assigned, so on presets made before renaming, the scribble strips show the old name on switches that aren't selected. Blocks you add from now on get the new names. If you added your presets in step 4, step 7 puts the fixed ones back.

HX Edit still shows Line 6's names. It reads them from its own model list on your computer, not from the unit. Your presets are fine either way: they store each model's ID, not its name.

7

Import your setlist

If you added your setlist in step 4. Do this after the firmware is installed.

  1. If you got a .zip, open it to get the file inside.
  2. Open HX Edit with your unit connected.
  3. Setlist: import the fixed .hls (the import at the top of the preset list). It replaces every preset on the unit with the fixed ones, in the same slots.
  4. Single presets instead: select the slot each one came from, choose Import, and pick its .hlx file (or drag it onto the slot). Importing replaces what's in that slot.
  5. Select a preset on the unit: switches that aren't selected now show your names too.

Presets you make from now on get the new names on their own. Keep your HX Edit backup from step 1 until you've checked everything.

!

Recovery

If the unit doesn't start, or you want the original names back.

  1. Turn the unit off, then start it in update mode:
    • HX Effects: hold the right arrow (>) while you turn it on.
    • HX Stomp: hold Page Right while you turn it on (what nocaseguy's README uses). Line 6's own manual says to hold footswitches 2 and 3, so if one doesn't work, try the other.
    • HX Stomp XL: the same as the Stomp. Recovery hasn't been tried on an XL yet.
  2. In Line 6 Updater, install the stock 3.80.0 .hxf for that unit (or your NAM A2 Lite build). Never another unit's file.
What exactly does this change?

Three names per model: two in the unit's main application (the model list, and the model's own name) and the display name in its model database. New display names are added to the database's string table, and each renamed model points to its new one; nothing else in the database changes. Then every checksum: the application's image CRC, the database's string-table CRC, each archive entry's CRC32 and Fletcher sums, the payload MD5 and the size fields. Setting every name back to Line 6's gives you the original file, byte for byte.

Why is NAM A2 Lite locked?

Its name comes from the NAM A2 Lite build, so this page leaves it alone. On the HX Effects it takes over the Xenomorph Fuzz Mono slot, and the stereo Xenomorph Fuzz is still the real fuzz, so you can rename that one.

Do the Stomp and XL get suggested names?

Yes, for everything with a real amp, cab or pedal behind it: the effects get the same names as on the HX Effects, and amps, preamps and cabs get names based on helixhelp.com's "Based on" list (Jason Shimkoski's Helix model reference). Line 6 Originals keep their names.
