HX Effects · HX Stomp · HX Stomp XL · Model Renamer

Rename the models on your HX

Drop in your firmware and give every model a name that says what it is: Boss SD-1 instead of Stupor OD. Then download a new .hxf with every checksum fixed. It all runs in this browser. Nothing is uploaded anywhere.

Unofficial and experimental. This isn't made or supported by Line 6, and installing modified firmware is at your own risk. Only the model names change: no sound, preset or NAM code is touched. If anything goes wrong, the Recovery steps put the stock firmware back.

Install it

The same way as any Line 6 update.

  1. In HX Edit, back up your presets and IRs, then close HX Edit.
  2. If you got a .zip, open it to get the .hxf inside. Open Line 6 Updater, choose Choose File, and pick the renamed .hxf.
  3. Let it finish, and let the unit restart on its own.
  4. Open the model list: Distortion should now show Boss SD-1 where Stupor OD was.

Footswitch labels in your existing presets keep Line 6's names. A preset saves each footswitch's label when its block is assigned, so on presets made before renaming, the scribble strips show the old name on switches that aren't selected. Blocks you add from now on get the new names. To update an older preset, re-pick the model on that switch or edit its label.

HX Edit still shows Line 6's names. It reads them from its own model list on your computer, not from the unit. Your presets are fine either way: they store each model's ID, not its name.

!

Recovery

If the unit doesn't start, or you want the original names back.

  1. Turn the unit off, then start it in update mode:
    • HX Effects: hold the right arrow (>) while you turn it on.
    • HX Stomp: hold Page Right while you turn it on (what nocaseguy's README uses). Line 6's own manual says to hold footswitches 2 and 3, so if one doesn't work, try the other.
    • HX Stomp XL: the same as the Stomp. Recovery hasn't been tried on an XL yet.
  2. In Line 6 Updater, install the stock 3.80.0 .hxf for that unit (or your NAM A2 Lite build). Never another unit's file.
What exactly does this change?

Three names per model: two in the unit's main application (the model list, and the model's own name) and the display name in its model database. New display names are added to the database's string table, and each renamed model points to its new one; nothing else in the database changes. Then every checksum: the application's image CRC, the database's string-table CRC, each archive entry's CRC32 and Fletcher sums, the payload MD5 and the size fields. Setting every name back to Line 6's gives you the original file, byte for byte.

Why is NAM A2 Lite locked?

Its name comes from the NAM A2 Lite build, so this page leaves it alone. On the HX Effects it takes over the Xenomorph Fuzz Mono slot, and the stereo Xenomorph Fuzz is still the real fuzz, so you can rename that one.

Do the Stomp and XL get suggested names?

For effects, yes: the same names as the HX Effects, matched by Line 6 name. Amps, preamps and cabs keep Line 6's names until you change them.
